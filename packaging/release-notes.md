丸丸小帮手 v0.3.3 Windows 自用版。按用户明确授权继续未签名发行，EXE 未做 Authenticode 签名；请从本仓库 Release 下载并核对 SHA-256 清单。

本版将开发、测试和 Windows 构建统一迁移到 uv，加入项目锁文件并固定 Python 3.14。原有 30 项 Python 依赖版本全部保留，现有功能和文件处理方式延续上一版。

修复构建所需 FFmpeg 上游滚动下载链接失效的问题：继续使用 FFmpeg 8.1.3，保存归档中的 223 个文件与原始解包清单逐项 SHA-256 一致；原上游来源及归档校验信息保留在仓库中。

下载 `WanwanTeacherHelper-v0.3.3-windows-x64.exe` 即可运行，无需安装 Python、Office 或 FFmpeg。原件只读，先预览再处理，结果另存；同名输出自动编号。

从 v0.3.1 及更早版本首次自动更新时，旧更新器仍可能在替换后重启时提示找不到 `python314.dll`。关闭提示，再从原位置手动打开程序即可；也可直接下载本版 EXE。v0.3.2 已包含重启修复，本版继续保留。

Windows CI 执行功能与界面测试，并对目录版、单 EXE、无 Python PATH 和普通账户离线环境进行验收。验证结果、界面截图、SBOM、第三方许可、`UnsignedSelfUse` 状态及 SHA-256 清单随发行提供。

真实 Office/WPS 画面、字体、动画、播放、打印及园所现场仍需在对应环境验收。PDF 不保留书签，表单、签名、注释和链接不处理；视频使用 MPEG-4/AAC。请先用材料副本试用并复核输出。
