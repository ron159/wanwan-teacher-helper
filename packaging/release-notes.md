丸丸小帮手 v0.3.1 Windows 自用版。EXE 未做 Authenticode 签名，下载时或首次启动时 Windows 可能提示未知发布者；请从本仓库 Release 下载并核对 SHA-256 清单。

本次新增通信簿：支持导入 .xlsx/.xls、粘贴多行信息、识别学生与家长姓名和电话、预览去重、搜索、编辑与删除。识别不完整时显示可复制示例并保留原文供核对。联系人保存在当前电脑的用户目录，不与小程序自动同步。界面删除口号式文案，改为功能提示。照片批量调整、Word 多图排版、文档激进瘦身与自动更新继续提供。

下载 `WanwanTeacherHelper-*-windows-x64.exe` 即可运行，无需安装 Python、Office 或 FFmpeg。原件只读，先预览再处理，结果另存；同名输出自动编号。

Windows CI 执行功能与界面测试，并对目录版、单 EXE、普通账户离线环境进行验收；冻结程序还检查通信簿识别与本地保存。验证结果、界面截图、SBOM、第三方许可、未签名状态及 SHA-256 清单随发行提供。

真实 Office/WPS 画面、字体、动画、播放、打印及园所现场仍需在对应环境验收。PDF 不保留书签，表单、签名、注释和链接不处理；视频使用 MPEG-4/AAC。请先用材料副本试用并复核输出。
